# CalculatorDesing_WPF
Es una calculadora en C# usando WPF, que simula la interfaz de un teléfono móvil con una imagen de fondo. Ofrece funciones básicas (suma, resta, multiplicación, división) y una experiencia intuitiva con botones responsivos. Ideal para usuarios que buscan una herramienta de cálculo funcional y atractiva.

## Descripción
CalculatorDesing_WPF es una calculadora desarrollada en C# utilizando WPF, que simula la interfaz de un teléfono móvil con una imagen de fondo. Ofrece una experiencia intuitiva y moderna.

## Características
- **Interfaz Atractiva:** Diseño que imita un celular.
- **Funcionalidad Completa:** Suma, resta, multiplicación y división.
- **Interactividad:** Botones responsivos y fáciles de usar.
- **Uso de WPF:** Interfaz rica y dinámica con animaciones.

## Tecnologías Utilizadas
- **Lenguaje:** C#
- **Framework:** WPF (Windows Presentation Foundation)
- **Diseño:** XAML
