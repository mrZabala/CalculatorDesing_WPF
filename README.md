# CalculatorDesing_WPF  CalculatorDesing_WPF es una calculadora en C# usando WPF, que simula la interfaz de un teléfono móvil con una imagen de fondo. Ofrece funciones básicas (suma, resta, multiplicación, división) y una experiencia intuitiva con botones responsivos. Ideal para usuarios que buscan una herramienta de cálculo funcional y atractiva.
